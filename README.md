#  IPL Analysis Dashboard
## Project Overview

This project is an interactive **IPL Analysis Dashboard** developed using **Microsoft Power BI**.

The dashboard analyzes IPL player and team performance using batting, bowling, franchise, and player nationality data.

##  Objective

The objective of this project is to transform IPL player data into meaningful visual insights and provide an interactive dashboard for analyzing player and team performance.

## Tools Used

* **Power BI**
* **Power Query**
* **DAX**
* **CSV Dataset**

## Dashboard Highlights

* Total Runs
* Strike Rate
* 4s and 6s
* Best Bowling
* Bowling Economy
* Bowling Strike Rate
* Bowling Average
* Tournament 4s and 6s
* India vs Overseas player analysis
* IPL franchise analysis
* Player-wise performance analysis

##  Interactive Features

The dashboard allows users to:

* Select an IPL franchise.
* Select a batsman and analyze batting performance.
* Select a bowler and analyze bowling performance.
* Compare Indian and overseas players.
* Analyze player and franchise performance through interactive visuals.

## Key Insights

The dashboard helps users understand:

* Batting and bowling performance of IPL players.
* Differences between Indian and overseas players.
* Franchise-level batting performance.
* Player performance based on runs, boundaries, and strike rate.
* Bowling performance based on economy, average, and strike rate.
