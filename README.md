IPL Analysis Dashboard
📊 Project Overview

The IPL Analysis Dashboard is an interactive Power BI dashboard developed to analyze IPL player and team performance.

The dashboard transforms player-level IPL statistics into meaningful visual insights covering batting, bowling, player nationality, franchise performance, and tournament statistics.

🎯 Objective

The objective of this project is to analyze IPL player performance and present the results through an interactive and easy-to-understand Power BI dashboard.

The dashboard allows users to select teams, batsmen, and bowlers to explore their performance in detail.

🛠️ Tools & Technologies
Microsoft Power BI
Power Query – Data cleaning and transformation
DAX – Measures and calculations
